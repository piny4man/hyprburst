# Contributing

Thanks for considering a contribution to Hyprburst.

## Scope

Hyprburst is maintained for a focused Arch Linux and Hyprland workflow. Changes should preserve fast startup, predictable terminal behavior, and a small configuration surface.

## Before Opening A Change

- Keep changes focused and minimal.
- Run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo test` before submitting code changes.
- Update documentation when user-facing behavior changes.
- Do not include generated build output or local configuration files.

## Official Maintainer Control

All official releases, crates.io ownership, AUR ownership, repository administration, and merge rights remain controlled by the project owner. See [MAINTAINERS.md](MAINTAINERS.md).

## Code Of Conduct

Contributors are expected to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
